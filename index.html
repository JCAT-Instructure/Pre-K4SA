Implementation Appendix & Setup Guides

Direct configuration workflows and setup guides for technical and instructional design teams building the Pre-K 4 SA proposal and implementation plan.

Canvas Career Setup Workflow

  1. Configure User Roles: Access Account Settings > Permissions. Customize default roles (Learner, Facilitator, Designer) to eliminate academic clutter.
  2. Enable Skillspace: Turn on Skillspace in Feature Options to allow adult learners to track skill tiers dynamically. Driven by Ignite AI, Skillspace dynamically recommends training based on real-time role performance.
  3. Create Role Pathways: Build structured, role-based training pipelines tailored specifically for Center Directors vs. Classroom Educators to guide professional progression without quiz score gating.

Reference: Official Instructure Community Canvas Career Setup Guide.

Canvas Catalog & External Portal Setup Workflow

  1. Configure Root Portal & SASSA Subcatalogs: Establish custom domain branding with tailored CSS/JS for Pre-K 4 SA visual identity.
  2. Setup User Defined Fields (UDFs): In Catalog Settings > User Defined Fields, create electronic signature checkboxes for MOUs and provider contact data collection.
  3. Configure Certificate Templates: Set up automated PDF certificate generation upon course or program completion for immediate partner verification.
  4. Publish Listings & Programs: Group Canvas LMS courses into promotional Catalog listings with capacity limits and waitlists.

Reference: Official Instructure Community Canvas Catalog Administration Guide.

Canvas Studio Integration Workflow

  1. Enable LTI 1.3 Advantage Tool: Embed Studio into the Rich Content Editor (RCE) across all course shells.
  2. Configure Video Annotations: Enable timestamped inline comments for instructional coaching feedback on CLASS observations.
  3. Set Up Viewing Analytics: Utilize Studio Insights to track exact viewing duration per educator for verified PL credit.

Reference: Official Instructure Community Canvas Studio Deployment Guide.

Canvas Ignite AI & Intelligent Insights Workflow

  1. Account Feature Toggles: Enable Ignite AI Discussion Summaries, Automatic Translations, and Rubric Generator in Account Settings.
  2. Generate CLASS Rubrics**: Open Rubric Builder > Generate with AI. Input domain parameters (Emotional Support, Classroom Organization, Instructional Support). (Note: Rubric engine available in Canvas Academic; see bottom note).
  3. Configure "Ask Your Data": Assign Intelligent Insights permissions to administrative personnel for conversational query access.

Reference: Official Instructure Community Ignite AI & Intelligent Insights Guide.
